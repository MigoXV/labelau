# LabelAU 使用说明

LabelAU 是一个用于 WAV、FLAC、MP3 音频标注的桌面工具，支持浏览目录、播放音频、在波形和频谱上标注语音区间，并导出 Audition 兼容的 CSV 文件。

## 使用步骤

1. 点击“打开目录”，选择包含 WAV、FLAC 或 MP3 文件的目录；云服务器模式下会打开服务器目录浏览器。
2. 系统会递归扫描目录，自动匹配同目录下同名的 CSV 标注文件。
3. 如果目录里存在损坏或不支持的音频，系统会自动跳过，并在界面底部提示跳过数量。
4. 云服务器模式下，可使用左侧“导入音频”选择本地目录上传；其中的 WAV、FLAC 或 MP3 会按目录结构导入到当前服务器目录。
5. 从左侧文件列表选择一个音频，开始播放、查看波形和频谱。
6. 在波形图或频谱图中拖拽即可新增标注区间。
7. 切换到擦除工具后，再次拖拽可删除已有区间。
8. 点击“保存 CSV”后，当前标注会写入与音频同名的 CSV 文件。
9. 需要交付数据集时，可点击“导出 AudioFolder”下载 Hugging Face `AudioFolder` 兼容 zip；当前仅导出已有标注的音频。

## 引擎功能

LabelAU 可选接入外部 gRPC 引擎，用于 WAV 音频的自动预标注和临时降噪。

- 点击“引擎设置”可在界面中编辑 VAD 和降噪 gRPC 地址。
- `LABELAU_VAD_GRPC_URL`：VAD 引擎默认地址，例如 `127.0.0.1:50051`。
- `LABELAU_DENOISE_GRPC_URL`：降噪引擎默认地址，例如 `127.0.0.1:50052`。
- `LABELAU_DATA_ROOT`：云服务器目录浏览器允许访问的根目录；未配置时优先使用 `/data-bin`，不存在则使用当前工作目录。
- 界面中保存的地址优先于环境变量；清空界面配置后会回退到环境变量默认值。
- VAD 和降噪第一版仅支持 16-bit PCM WAV。MP3 / FLAC 仍可手工标注，但不会送入引擎。
- “VAD 预标注”会在当前文件没有标注时直接写入检测区间；如果已有标注，会先确认是否强制覆盖。
- “降噪”只在当前会话中生成临时音频，不落盘、不参与目录扫描。使用降噪音频继续标注时，CSV 仍保存到原音频对应的同名 CSV。
- 每个音频只允许生成一次降噪结果；已有降噪结果后，同一个按钮会在“显示原始音频”和“显示降噪音频”之间切换，防止对降噪音频再次降噪。
- 启用降噪后，可在同一文件的两套波形、频谱和播放源之间切换，用于对比降噪效果。
- 当前会话会缓存最近 8 个音频文档；切换到其他音频再返回时，已生成的降噪结果通常无需重新计算，除非缓存被后续文件挤出。

## 常用操作

- 左侧列表可按文件名、目录和任务状态筛选。
- “未处理 / 未保存 / 已处理”可快速查看任务进度。
- 波形图适合快速浏览时间范围，频谱图适合精细调整。
- 多声道音频可在频谱上方切换声道查看。
- 如果当前文件有未保存修改，关闭应用时会提示是否保存后退出。

## 快捷键

- `空格`：播放 / 暂停
- `S` 或 `Ctrl+S` / `Cmd+S`：保存当前 CSV
- `Ctrl+Z` / `Cmd+Z`：撤销上一步标注
- `M`：切换到标注工具
- `E`：切换到擦除工具
- `V`：切换到拖拽查看模式
- `X`：切换线性 / 对数频率缩放
- `R`：切换播放倍率
- `↑ / ↓`：切换上一条 / 下一条音频
- `← / →`：平移当前时间窗口

## 注意事项

- 当前支持 WAV、FLAC、MP3 音频文件。
- CSV 会保存为与音频同目录、同文件名的 `.csv` 文件。
- `导出 AudioFolder` 会基于磁盘上已有的 CSV 生成 `test/metadata.jsonl + 音频` 的 zip 包。
- 未保存状态会在界面底部显示，请在切换任务或退出前确认是否需要保存。
- 如果目录中没有可用音频，界面会提示未找到可导入文件。

## Docker 打包

当前项目维护两个镜像：

- `registry.cn-hangzhou.aliyuncs.com/migo-dl/labelau-frontend`
- `registry.cn-hangzhou.aliyuncs.com/migo-dl/labelau-service`

默认打包版本为 `0.2.0a1`，默认 npm 源为官方源 `https://registry.npmjs.org`，避免新发布的 `svara-ui` 在镜像构建时遇到镜像站同步延迟。

构建并推送 `0.2.0a1`：

```bash
pnpm run docker:build:0.2.0a1
```

仅构建、不推送：

```bash
pnpm run docker:build
```

脚本位置：

```bash
scripts/docker-build.sh
```

如果后续确认镜像站已同步，也可以手动覆盖 npm 源：

```bash
NPM_REGISTRY=https://registry.npmmirror.com \
bash scripts/docker-build.sh 0.2.0a1 --push
```
